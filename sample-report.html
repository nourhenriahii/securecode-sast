HighRunning text as code (eval/exec)
test_samples/vulnerable.py:13
eval(user_input)                                   # BAD

What it means: eval() and exec() run text as if it were code. If any part of that text comes from a user, they can run their own commands on your machine.

How to fix: Avoid eval/exec. For data use json.loads or ast.literal_eval; for logic use normal functions or a lookup table.

What it means: The SQL query is built by joining strings with user data. An attacker can change the query to read, modify or delete the whole database.

HighShell command via os.system
test_samples/vulnerable.py:33
os.system("ls " + user_input)                            # BAD

What it means: os.system/os.popen run a shell command. If the text includes user input, it can be abused to run other commands.

How to fix: Use subprocess.run([...]) with a list of arguments and no shell.

MediumShell command injection risk
test_samples/vulnerable.py:14
subprocess.run("ls " + user_input, shell=True)     # BAD

What it means: shell=True hands the command to the system shell. Input such as '; rm -rf ~' can add extra commands (command injection).

How to fix: Pass the command as a list and drop shell=True: subprocess.run(['ls', folder]).

MediumAppleScript injection
test_samples/vulnerable.py:34
script = f'tell application "Messages" to send "{user_input}"'   # AppleScript injection

What it means: An AppleScript is built from text with unescaped values. A crafted value can break out of the quotes and run extra commands (for example 'do shell script').

How to fix: Escape every value (backslashes and quotes) before inserting it, or pass values as arguments instead of building the script from strings.

MediumServer open to the whole network
test_samples/vulnerable.py:35
app.run(host="0.0.0.0", debug=True)                      # Flask debug

What it means: The server listens on 0.0.0.0, so every device on the same network can reach it, not only your computer.

How to fix: Use 127.0.0.1 if only you need it. If it must be reachable, require a strong token and use HTTPS or a VPN.
